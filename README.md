# F_nubes_ciencia_de_datos_en_produccion

Repositorio del PI M5 de Fundamentos de nube y ciencia de datos en produccion.

El entregable principal esta en `mlops_pipeline/` y esta organizado por avances:

- Avance 1: carga de datos, EDA, estructura, requirements y notebooks.
- Avance 2: feature engineering, entrenamiento, evaluacion y artefactos del modelo.
- Avance 3: monitoreo de data drift y aplicacion Streamlit.
- Avance 4: API FastAPI, prediccion batch y Docker.

La base correcta del PI es `mlops_pipeline/Base_de_datos.csv`, con 10,763 registros de creditos historicos y objetivo `Pago_atiempo`.

`lectures_txt/` y `materials/` estan ignorados para que no se suban al repositorio.
